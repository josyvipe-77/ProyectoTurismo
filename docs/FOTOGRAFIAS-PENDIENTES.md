# Fotografías del catálogo

Revisión: 2026-10-19.

El catálogo tiene 135 referencias: 107 con galería local (552 imágenes) y 28 pendientes de una imagen identificada.

Las fotografías incorporadas proceden de la ficha específica de cada recurso en MINCETUR. Las fuentes, fechas de consulta y huellas SHA-256 se conservan en `src/data/mincetur-photos.json` y `public/images/mincetur/provenance.json`. El crédito del inventario no atribuye autoría individual ni una licencia abierta.

## Pendientes

Los registros históricos necesitan confirmar primero la identidad actual del recurso. Las tarjetas muestran una imagen de contexto identificada con su lugar de origen; no se cuenta como fotografía propia del recurso. La selección está en `src/data/catalog-context-photos.json` y se regenera con `python research/build_context_photos.py`.

## Actualizar el archivo

```sh
python research/prepare_mincetur_photos.py
python research/audit_mincetur_photos.py
python research/build_photo_coverage.py
```

El importador reutiliza las fotos existentes y consulta las fichas oficiales del catálogo, incluidas celebraciones, gastronomía y lugares sin coordenadas. Nunca modifica los pins. Huayhuaca conserva el identificador local `waywaka` y enlaza a su ficha actual 13276. Las galerías se cargan al acercarse a la pantalla y se sirven en WebP con versiones pequeñas y ampliadas.
